Privacy

This is a static page hosted as a creator link page. It does not ship its own analytics, tracking scripts, or forms. Below is a plain-language overview of the few external services a typical deployment may rely on.

Hosting

LinkHavoc is a set of static files served by whichever hosting provider the page is deployed to (for example, Vercel, Cloudflare Workers, Netlify, or DigitalOcean App Platform). The hosting provider's logs may record standard request data such as IP address and user agent to operate the service. See the provider's own privacy policy for details.

Links to external content

The page surfaces links to external platforms (social profiles, video, music, email). When you click them, you leave LinkHavoc and are governed by the target service's own policies. Some embedded services may collect traffic data even when not actively used.

Questions

Contact the page owner directly for any questions about this page or the data the linked services collect.
